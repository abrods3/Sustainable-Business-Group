# Emory Sustainable Business Group website
Layout:
## Pages

| File           | Page        |
|----------------|-------------|
| `index.html`   | Home        |
| `about.html`   | About Us    |
| `clients.html` | Our Clients (current and past projects) |
| `team.html`    | Our Team (executive board, board of directors) |
| `events.html`  | Events      |
| `join.html`    | Join SBG    |
| `contact.html` | Contact     |

The shared styles are in `assets/css/styles.css`. The menu and footer are
built once in `assets/js/site.js`. Edit the `PAGES` list there to add or remove
menu links. Photos and logos go in `images/` (see `images/README.md`).

To preview the site, open `index.html` in a browser. To publish it, upload
the whole folder to any static host, such as GitHub Pages or Netlify.
